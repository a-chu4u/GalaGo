## 🌏 About GalaGo

**GalaGo** is a web-based tourism information and travel planning system designed to help visitors discover and explore tourist destinations across **Palawan, Philippines**.

The platform brings together destination information, interactive maps, real-time weather data, route planning, favorites, and travel itineraries in one convenient website.

GalaGo also includes an administrative dashboard for managing tourist destinations and tourism-related information.

---

## ✨ Key Features

### 🧳 For Visitors

| Feature | Description |
|:---|:---|
| 🏝️ **Explore Destinations** | Discover tourist spots across Palawan. |
| 📍 **Destination Details** | View descriptions, locations, categories, and images. |
| 🗺️ **Interactive Maps** | Explore destinations using Leaflet and OpenStreetMap. |
| 🌤️ **Weather Updates** | Check destination weather using Open-Meteo. |
| 🚗 **Route Planning** | Calculate travel routes using OpenRouteService. |
| ❤️ **Favorites** | Save preferred destinations for easy access. |
| 📅 **Travel Itinerary** | Create, edit, and organize travel plans. |
| ⭐ **Reviews & Ratings** | Share experiences through destination reviews. |
